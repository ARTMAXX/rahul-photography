| Signal | Action |

| GBP suspension warning | Fix immediately (name, address, categories) |
| Review rating drops < 4.5 | Audit last 10 reviews, reply to all, ask happy clients |
| Search views drop > 20% MoM | Check: posts stopped? photos stale? reviews stalled? |

| NAP mismatch found | Fix everywhere same day |
